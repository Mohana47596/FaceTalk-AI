# 📌 Overview

FaceTalk AI is an advanced real-time 3D virtual companion that allows users to interact with a highly realistic animated avatar through natural voice conversations. The application combines modern web technologies, AI-powered Large Language Models (LLMs), premium Text-to-Speech (TTS), and real-time facial animations to create an immersive human-like communication experience.

Users can upload a face image to personalize the avatar and engage in intelligent conversations with natural lip synchronization and expressive animations.

# 🔄 Working Flow

1. User opens the FaceTalk AI application.
2. User uploads a face image to personalize the avatar.
3. Voice input is captured through the microphone.
4. Speech is converted into text.
5. The prompt is processed by Groq Llama 3.3 70B.
6. Gemini acts as a fallback when required.
7. The generated response is converted into speech.
8. The avatar performs realistic lip-sync and facial animations.
9. The user continues the conversation in real time.
